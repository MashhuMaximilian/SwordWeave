# The three v0.1 alpha manuscripts

These are the complete current book sources, not the former partial drafts:

- `players-handbook.md`: teaches all player procedures and includes the base construction reference, complete character/item/creature examples, quick reference, glossary, rights notice and topic index.
- `game-masters-guide.md`: teaches a first session, rulings, shared rounds, creation/consequence review, creatures, encounters, recovery, adventures and campaigns; includes public sample links, worksheets and worked records.
- `system-reference-document.md`: states the same mechanics precisely, reproduces the principal 29 primitive families and explains creating primitives, effects, capabilities, heritages, characters, items, creatures and encounters.

The build validates identical primitive-reference text in PHB/SRD and identical worked records in all three. Acquisitions, Item BU and execution Cost stay separate. Prices are suggested anchors and examples are labelled; no fixed class or exhaustive bestiary is invented.

One accepted alpha placeholder remains: additional Vitality upkeep repayment triggered by incoming damage. The threshold, counter/reset and excess handling await the creator. Do not silently adopt the historical proposal.

`../../../scripts/build-books.py` generates the web-reader data and light/dark PDFs. See the parent publication README and release manifest for delivery and checks. Real table testing and future errata remain ongoing alpha work.
