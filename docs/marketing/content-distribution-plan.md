**Distribution** means placing links and useful materials where interested players and creators can encounter them. A creator kit is a small public collection of the project description, screenshots, logos, current books, alpha limitations and contact details for someone considering coverage. A short demonstration is a captioned recording of one real workflow or rules example. An itch.io listing is a tabletop-game project page presenting the current release and directing people to its files and website.

These are successive deliverables, not an instruction to launch every channel immediately. The founder's personal outreach can use the kit and examples once ready. Public Markdown is another representation of the approved content, generated as described in the [AI plan](ai-discovery-plan.md).

### Deferred brief: homepage

Opening explanation: SwordWeave is a free modular tabletop roleplaying game with browser tools for building characters and abilities. Identify v0.1 alpha and the intended table experience. Explain a reusable rule/construction example in ordinary terms before assuming readers know “primitives,” “Manifest” or “Atelier.”

Keep one clear start path for a GM trying the game, another for someone exploring character creation, and a visible current-book path. Avoid adding every research keyword to the hero or changing the visual design just to insert search terms.

### Deferred brief: first-session path

Start with a GM preparation checklist and a clear set of materials. Distinguish required from optional tools/accounts/Discord. Say how to choose starting access and where the quick reference lives. If there is no ready short adventure or pregenerated set, name that gap and author it before claiming “play tonight in ten minutes.”

Include one illustrative scene and an optional short feedback route. Do not infer a maximum player count, exact preparation duration or beginner suitability without rules evidence and a real check. The content should reduce the commitment from adopting a campaign to trying a prepared session.

### Deferred brief: new worked ability

Choose an idea that expresses SwordWeave’s actual strengths. Show the initial fictional intent, owned access, selected mechanics and table conversation; show a constraint or consequence, not just an impressive result. If an existing character inspires the example, distinguish actual saved mechanics from hypothetical additions.

If this content is reopened later, the same example could supply a written section and captioned demonstration. For the current release, start with a brief tour of the existing PHB reader/downloads; no new ability tutorial is required. Add VideoObject only when there is an actual published video matching the metadata.

### Brief: creator kit

Provide a short and a longer description, current version, clear alpha limitations, official website/books/Discord/contact, a few current screenshots, approved logo assets and credit/use instructions. Link the actual AI-use and publication disclosures. Do not promise blanket reuse rights over all artwork or fonts.

Offer an honest look at the alpha, not guaranteed favorable coverage. Let creators decline or criticize. A kit should remove research friction without imposing a contract or asking them to download private project files.

itch supports tabletop classification and creator-controlled project pages; its documentation is the setup reference, not evidence of guaranteed exposure. [Official itch guide](https://itch.io/docs/creators/getting-started).

Do not create a Google Business Profile for a fictional shop/location, a mass of directory listings, a Wikipedia article for promotion, fake review accounts or automated “community engagement.” Independent useful coverage is earned by having something worth trying and making it easy to evaluate.
