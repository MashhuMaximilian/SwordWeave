# SwordWeave Companion terms draft for owner review

The publisher needs a publicly accessible terms page approved for the service before submitting the plugin. These notes document the service behavior for that page.

## Service

SwordWeave is a tabletop roleplaying game and character management website. SwordWeave Companion is an optional connection to ChatGPT that can find Play Guide material and catalogue entries, preview character builds, read available saved sheets, and return links to sheet PDFs and monster companions. Players save changes on the SwordWeave website.

## Accounts and sharing

The connection uses the player's existing SwordWeave account. SwordWeave checks the permissions on each character and creation it retrieves. Players can manage their sheets and sharing settings in SwordWeave. The connection can be removed from ChatGPT's plugin settings.

## ChatGPT and privacy

ChatGPT processes requests and displays the results according to the player's ChatGPT settings and OpenAI's terms. SwordWeave's [privacy notice](https://www.swordweave.quest/privacy) describes account linking, returned game content and the project's data contact.

## Contact

For help with SwordWeave accounts, content or the connection, use the [SwordWeave contact page](https://www.swordweave.quest/contact) or email `contact@swordweave.quest`.
