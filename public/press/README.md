# SwordWeave creator kit

v0.1 alpha · 21 October 2026

Created by Marius Ion (Mashu). Official kit: https://www.swordweave.quest/press

## Start here

- `fact-sheet.md`: one-line, short and longer descriptions, current status, books, official links and AI disclosure.
- `logos/`: the three existing flat PNG marks plus the navigation's exact gold-and-teal gradient mark as transparent PNG and self-contained SVG. The SVG retains the original raster alpha mask with a vector gradient.
- `materials/`: an original two-page first-session run sheet and three-page Neris construction companion. The PHB-style ivory, teal and metallic typography carries into both; Neris also includes the existing three heritage portraits beside their explanations. Both PDFs are printable and fillable; their complete text and prompts are supplied as Markdown and can also be read on the creator-kit page.
- `previews/`: the illustrated PHB cover, first-page previews rendered from the two current companion PDFs, and the actual public Neris character sheet. The companion previews link to the complete two/three-page PDFs in `materials/`; they are not PHB excerpts.
- `captions.md`: descriptions, source editions, credits and notices for every image.
- `asset-manifest.json`: dimensions, byte counts, source information and SHA-256 hashes.
- `asset-notices.md`: license boundaries. Read this before reusing a file.
- `repository-license.txt`: the existing repository license, preserved for reference.
- `press-kit.json`: the public source data used to build the page and text files.

## Current books

Visit https://www.swordweave.quest/books to choose a reader and current PDF edition. Full book PDFs are not duplicated in this archive; the two original companion PDFs are included. The illustrated PHB and GM Guide PDFs are available for the current alpha. The GM Guide’s 268-page organic-edge revision has a 76.5 MB reading PDF and a 309 MB full-resolution PDF. The standalone 78-page SRD Reference edition is available as a 14.5 MB PDF; its earlier dark PDF remains available. Online readers and PDFs can differ, and the three books are not yet a synchronized final set, so identify the book and edition when quoting rules.

## Reproducible archive

The source repository includes `scripts/build-press-kit.py`. It rebuilds the text, manifests and ZIP from the checked-in originals without image generation, external downloads or private account data. The archive uses sorted entries and a fixed date from the source data.

After changing a companion PDF, run `scripts/render-companion-previews.py` with Poppler/Pillow before building the kit. It renders the actual first pages and records their dimensions and source PDF hashes. The archive builder rejects a preview whose recorded source PDF hash is stale.

The original companions are generated by `scripts/build-companion-materials.py` from the checked teaching data; export the current Neris data first with `pnpm exec tsx scripts/export-companion-source.ts`. The PDF builder uses ReportLab, existing OFL project fonts and a local fontTools conversion if required. Existing portrait exports and their checked source records are kept in `scripts/companion-assets/`; no artwork is generated during rebuilding. Render and validate every page/field before copying final PDF/Markdown outputs from `output/pdf/` into `public/press/materials/`. No book page is substituted for a companion.
