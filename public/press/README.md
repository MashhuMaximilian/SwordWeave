# SwordWeave creator kit

v0.1 alpha · 20 October 2026

Created by Marius Ion (Mashu). Official kit: https://www.swordweave.quest/press

## Start here

- `fact-sheet.md`: one-line, short and longer descriptions, current status, books, official links and AI disclosure.
- `logos/`: the three existing flat PNG marks plus the navigation's exact gold-and-teal gradient mark as transparent PNG and self-contained SVG. The SVG retains the original raster alpha mask with a vector gradient.
- `materials/`: an original two-page first-session run sheet and three-page Neris construction companion. Both PDFs are printable and fillable; their complete text and prompts are supplied as Markdown and can also be read on the creator-kit page.
- `previews/`: actual exports from the published illustrated Player’s Handbook. Further public tool screenshots, when listed in the manifest, show the real website.
- `captions.md`: descriptions, source editions, credits and notices for every image.
- `asset-manifest.json`: dimensions, byte counts, source information and SHA-256 hashes.
- `asset-notices.md`: license boundaries. Read this before reusing a file.
- `repository-license.txt`: the existing repository license, preserved for reference.
- `press-kit.json`: the public source data used to build the page and text files.

## Current books

Visit https://www.swordweave.quest/books to choose a reader and current PDF edition. PDFs are not duplicated in this archive. The illustrated PHB is complete for the current alpha; the GM Guide and SRD are being revised. Online readers and PDFs can differ, so identify the book and edition when quoting rules.

## Reproducible archive

The source repository includes `scripts/build-press-kit.py`. It rebuilds the text, manifests and ZIP from the checked-in originals without image generation, external downloads or private account data. The archive uses sorted entries and a fixed date from the source data.

The original companions are generated by `scripts/build-companion-materials.py` from the checked teaching data; export the current Neris data first with `pnpm exec tsx scripts/export-companion-source.ts`. The PDF builder uses ReportLab, existing OFL project fonts and a local fontTools conversion if required. Render and validate every page/field before copying final PDF/Markdown outputs from `output/pdf/` into `public/press/materials/`. No book page is substituted for a companion.
