# Entity navigation icons

Original SVGs by Lorc, Delapouite, Skoll, and Caro Asercion from [game-icons.net](https://game-icons.net/), licensed under [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/). Artist names are preserved in the directory paths and SVG metadata. Runtime attribution is included on `/attributions`.

These unmodified silhouettes are bundled for reliable navigation loading. Metallic color is applied by CSS.
