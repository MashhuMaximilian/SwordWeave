### D2 — Fix engine max_vitality in full resolve path

**Objective:** The full resolve returns `max_vitality: 10` (primitive-only) but the single-target fast path uses `resolveMaxVitality()` which adds the baseline `(10 + PB) × level`. Make the full resolve path use the baseline formula too.

**Files:**
- Modify: `src/app/api/characters/[id]/resolve/route.ts` (around line 350, where `resolveModifiers(input, sourceNames)` is called)

**Steps:**

1. Read the route at line 348-352.
2. After `const resolved: ResolvedModifiers = resolveModifiers(input, sourceNames);`, compute the proper max_vitality:
   ```ts
   const baselineMaxVit = (10 + input.pb) * input.level;
   const primitiveDelta = resolved.totals[VITALITY_TARGETS.max] ?? 0;
   const maxVitFloor = (resolved.byTarget[VITALITY_TARGETS.max] ?? [])
     .filter((c) => c.op === "min" || (c.op === "set" && (c.tags ?? []).includes("min")))
     .reduce((max, c) => Math.max(max, c.value), -Infinity);
   const maxVitCeiling = (resolved.byTarget[VITALITY_TARGETS.max] ?? [])
     .filter((c) => c.op === "max" || (c.op === "set" && (c.tags ?? []).includes("max")))
     .reduce((min, c) => Math.min(min, c.value), Infinity);
   let maxVitFinal = baselineMaxVit + primitiveDelta;
   if (maxVitFloor !== -Infinity) maxVitFinal = Math.max(maxVitFinal, maxVitFloor);
   if (maxVitCeiling !== Infinity) maxVitFinal = Math.min(maxVitFinal, maxVitCeiling);
   resolved.totals[VITALITY_TARGETS.max] = maxVitFinal;
   ```
3. Verify with `curl https://www.swordweave.quest/api/characters/462f9048-b0da-4185-98db-d18027132c82/resolve | jq '.resolved.totals.max_vitality'` → should be ~298 (10+6)*18+10 = 298.

### C1 — Human-readable conditions dictionary (single source of truth)

**Objective:** Build a function `humanReadableCondition(token: string): string` that maps every engine condition token to readable text. Use it in:
- Character sheet modals (conditions section)
- /atelier preview modals
- Bottom drawer (only as `*` marker; full text in modal)

**Files:**
- Create: `src/lib/engine/condition-dictionary.ts`
- Modify: `src/components/characters/formula-modal.tsx` (conditions section)

**Steps:**

1. Create `src/lib/engine/condition-dictionary.ts`:
   ```ts
   export function humanReadableCondition(token: string): string {
     // self:proficient_in(X)
     const mProf = token.match(/^self:proficient_in\((\w+)\)$/);
     if (mProf) return `Proficient in ${mProf[1]}`;
     // self:stat|vitality_pct|<|0.5
     const mVital = token.match(/^self:stat\|vitality_pct\|([<>])\|(\d+\.?\d*)$/);
     if (mVital) {
       const op = mVital[1] === "<" ? "below" : "above";
       const pct = Math.round(parseFloat(mVital[2]) * 100);
       return `HP ${op} ${pct}%`;
     }
     // self:is_tracking
     if (token === "self:is_tracking") return "Tracking an active mark";
     // self:not_proficient / self:not_proficient_in(X)
     const mNotProf = token.match(/^self:not_proficient(?:_in\((\w+)\))?$/);
     if (mNotProf) return mNotProf[1] ? `Not proficient in ${mNotProf[1]}` : "Not proficient";
     // actor:damaged-last-round
     if (token === "actor:damaged-last-round") return "Damaged last round";
     // actor:prone
     if (token === "actor:prone") return "Prone";
     // target:Prone / target:Grappled / etc
     if (token.startsWith("target:")) return `Target is ${token.slice(7).toLowerCase()}`;
     // scene:dim / scene:loud / etc
     if (token.startsWith("scene:")) return `Scene is ${token.slice(6).toLowerCase()}`;
     // AND / OR (operators in compound chain)
     if (token === "AND" || token === "OR") return token;
     // Fallback: return the token as-is
     return token;
   }
   ```
2. Add AND/OR chain rendering: when `cond.kind === "compound"`, render tokens with human-readable text and explicit AND/OR joiners.
3. Use this in `formula-modal.tsx` conditions section instead of raw `tokens`.
